Privacy Policy — FormCap for Google Forms™

Effective Date: November 19, 2026 · Last Updated: November 19, 2026

Google Workspace APIs & Google API Services — Limited Use Compliance Disclosure:
The use of raw or derived user data received from Workspace APIs will adhere to the Google User Data Policy, including the Limited Use requirements. FormCap’s use and transfer to any other app of information received from Google APIs will also adhere to the Google Workspace APIs User Data and Developer Policy, including all Limited Use and AI/ML model training restrictions.

1. Data Access — Minimal OAuth Permissions & What Data We Access

FormCap is engineered on a least-privilege architecture using minimal non-Restricted Google OAuth scopes declared in appsscript.json, plus standard non-sensitive Google Workspace Marketplace identity scopes:

  • https://www.googleapis.com/auth/forms — Allows FormCap to read choice questions, tally choice response counts, update choice lists when options reach their configured cap, and automatically open or close a form on your configured schedule or total-response cap (including via background time-driven triggers).
  • https://www.googleapis.com/auth/drive.file — Non-sensitive per-file scope: grants access solely to the individual Google Sheet you explicitly select via the Google Picker dialog in the Sheet Sync tab to read choice options and optional per-choice capacity numbers. FormCap cannot see any other files or spreadsheets in your Google Drive, and never writes to or modifies your Google Sheets.
  • https://www.googleapis.com/auth/script.container.ui — Allows FormCap to render its 300px sidebar interface and Google Picker dialog inside Google Forms.
  • https://www.googleapis.com/auth/script.scriptapp — Allows FormCap to install, inspect, repair, and remove onFormSubmit and time-driven schedule/sync triggers for your configured forms.
  • userinfo.email & userinfo.profile — Standard non-sensitive Google Workspace Marketplace sign-in scopes included by Google Cloud Console for add-on installation. FormCap does not use your personal profile or email address for marketing.

Exact Google User Data Accessed:

  • Form Structure & Choice Tallies (Processed inside Google Apps Script): Question Item IDs, question titles, option labels, and choice response counts for the forms where you explicitly configure FormCap rules.
  • Linked Sheet Columns (Read-Only): Only the column values of the specific Google Sheet tab you explicitly link inside FormCap’s Sheet Sync tab.
  • APIs Never Accessed: FormCap never requests broad Google Drive access (drive / drive.readonly), broad Google Sheets access (spreadsheets / spreadsheets.readonly), Gmail, Google Calendar, Google Chat, Google Meet, Google Photos, YouTube, or Data Portability APIs.

2. Data Use & Prohibited Data Uses

  • How We Use Google User Data: Form questions, choice tallies, and linked Sheet columns are used solely to execute the deterministic Choice Limiter, Form Limiter & Schedule, and Sheet Sync rules you configure in the FormCap sidebar.
  • Prohibited Data Use Guarantee: Raw, derived, and aggregated/anonymized Google user data is never used for any purpose other than providing or improving user-facing features of FormCap. We strictly prohibit using Google user data for targeted advertising, personalized ads, retargeting, creditworthiness or lending determinations, or user profiling.

3. Data Transfer & Third-Party Sharing

  • 100% Inside Google Apps Script for Live Submissions & Syncs: Every live form submission tally, option removal, waitlist swap, response-cap close, scheduled open/close, and Sheet-to-Form sync runs deterministically inside Google’s Apps Script runtime. Respondent answers and respondent PII are never transmitted to FormCap’s backend or any third party.
  • Optional Setup-Time AI Assist (Third-Party AI Inference Subprocessor): Only when a form owner explicitly clicks Preview Plan in AI Quick Setup or Polish copy in the Limits tab are the form’s title, question titles, choice labels, and owner prompt (never respondent answers or personal data) sent over HTTPS/TLS to our stateless Google Cloud Run endpoint (formcap-backend) and forwarded to the OpenAI API solely to draft a JSON rule preview or closed-form message for owner review.
  • Billing Processor (Stripe): Optional FormCap Pro subscriptions ($5.00 USD/month) and billing portal sessions are processed by Stripe. FormCap never transfers Google Form or Sheet contents to Stripe.
  • Prohibited Data Transfer Guarantee: Raw, derived, and aggregated/anonymized Google user data is never sold, rented, or transferred to data brokers, advertisers, or any third parties for any purpose other than executing the user-requested feature, in strict compliance with the Google User Data Policy Limited Use requirements.

4. AI/ML Model Training Restrictions & Limited Use Compliance

  • Prohibited AI/ML Model Training: FormCap never uses raw, derived, or aggregated/anonymized Google Workspace user data to develop, train, fine-tune, or improve any internal, foundational, or general-purpose AI/ML models.
  • Prohibited Transfer to Third-Party AI/ML Services for Training: FormCap never transfers Google Workspace user data to any third-party AI/ML service that uses that data to train or improve its AI/ML models. Under OpenAI’s API data usage policies, data submitted through the OpenAI API is not used to train or improve OpenAI models.
  • Affirmative Limited Use Statement: “The use of raw or derived user data received from Workspace APIs will adhere to the Google User Data Policy, including the Limited Use requirements.”

5. Data Protection & Security

  • Encryption in Transit: All traffic between the Google Forms sidebar, Google Cloud Run, OpenAI API, and Stripe is encrypted using HTTPS / TLS 1.2+.
  • Per-Form & Per-User Isolation: FormCap rules are stored strictly inside Google Apps Script’s isolated PropertiesService.getDocumentProperties() and PropertiesService.getUserProperties() stores—never in shared global script properties and never in external databases.
  • Stateless AI Processing & Verified Webhooks: Our Cloud Run backend processes optional AI Quick Setup requests statelessly in memory without logging or storing form schemas. Stripe webhooks are cryptographically verified via HMAC-SHA256 signatures.

6. Data Retention & Deletion Policies

  • Form Schemas & Prompts (Zero External Retention): Form titles and question labels sent during optional AI Quick Setup or Copy Polish are processed in memory for the single HTTP request and discarded immediately.
  • Rule Configurations: Saved Choice Limiter, Form Limiter, and Sheet Sync rules remain inside your own Google Apps Script properties until you disable/unlink them or uninstall the add-on.
  • Subscription License Records: For Pro subscribers, our encrypted Cloud Storage license store retains only your Stripe customer/subscription ID, checkout email, subscription status, and generated FC-PRO-* license key while your subscription is active.
  • How to Revoke Access or Request Data Deletion: You can revoke FormCap’s OAuth access at any time via your Google Account Permissions page, or email sdai.code@gmail.com to request deletion of any associated subscription/license records (completed within 7 calendar days).
